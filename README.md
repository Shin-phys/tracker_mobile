# MotionTrace Mobile

トレースアプリ Ver.2 のスマートフォン専用版です。
追跡・スケール校正・平滑化のアルゴリズムは Ver.2 と同一（`src/utils/` をそのまま流用）なので、
同じ動画からは同じ数値が出ます。変えたのは **画面構成と入力方法だけ** です。

## 起動

```bash
npm install
npm run dev
```

`vite.config.ts` で `server.host: true` にしてあるので、起動時に表示される
`http://192.168.x.x:3000/` を同じ Wi-Fi のスマホで開けば実機で試せます。

ビルドは `npm run build`（出力は `dist/`）。

## 画面構成

```
┌──────────────┐
│ TopBar       │ OpenCV の準備状況・記録点数
├──────────────┤
│ 映像ステージ  │ ピンチズーム／パン、ツール操作
├──────────────┤
│ 再生バー      │ 再生・コマ送り・シーク・再生速度
├──────────────┤
│ シート        │ 対象／校正／設定／データ（高さ 3 段階）
├──────────────┤
│ タブバー      │
└──────────────┘
```

シートの上端の横棒はドラッグで高さを変えられます。タップで「半分 ⇄ 広い」、
同じタブをもう一度押すと閉じて映像が広くなります。

## 指の使い分け

映像の上では **指の本数で役割が変わります**。

| 操作 | 動き |
| --- | --- |
| 2本指ピンチ／ドラッグ | いつでも拡大縮小・移動 |
| 1本指 | 画面左のツールバーで選んだツールの操作 |

ツールは 4 種類です。

- **移動**（手のアイコン）— 1本指でも映像を動かす。誤操作を避けたいときの既定状態。
- **枠**（四角）— 追跡枠の指定。マーカーを**タップ**するとその点を中心に既定サイズの枠が置かれ、
  **ドラッグ**すれば任意サイズで囲めます。既定サイズは再生バーのスライダーで変更できます。
- **修正**（十字矢印）— 一時停止中に、ずれた追跡点をドラッグして正しい位置へ直します。
- **校正**（照準）— 校正タブで「指定を開始」を押すと現れます。

ドラッグ中は指で隠れる部分を **虫めがね**（3倍）で表示します。数 px の精度が要るときはこれを見てください。

## スケール校正

PC 版と同じ 3 モード（平面（四隅）／2点間／追跡枠の幅）です。スマホでは操作だけ変えています。

- **平面（四隅）**: 左上 → 右上 → 右下 → 左下 の順に**タップ**。
- **2点間**: 端から端まで**なぞる**か、**2回タップ**。
- 置いたあとは ● を直接ドラッグ、または校正タブの**十字キーで 1px ずつ**動かせます
  （キーボードが無いスマホでは、これが矢印キーの代わりです）。
- 校正が完了したあとは、タップしても点が置き直されません。
  やり直したいときは「四隅を取り直す」「線を引き直す」を押してください。

## グラフ概形確認モード

「データ」タブの一番上。**縦軸（x / y / vx / vy / 速さ）** と **横軸（t / x / vx）** を別々に選ぶ方式で、
x-t, y-t, vx-t, vy-t, y-x, vy-vx をすべて含みます。定番の組み合わせはショートカットのチップから 1 タップ。
右上の「拡大」で全画面表示になります。

これは飾りではなく**検証の道具**として置いています。

- **グラフをタップするとその時刻へ動画がシークします**（再生中なら自動で止まります）。
  vx-t / vy-t に鋭いスパイクが出ていたらそこで追跡が飛んでいるので、タップして飛び、
  映像の「修正」ツールで直す、という流れになります。
- **y-x と vy-vx は等縮尺**で描きます。縦横の縮尺が違うと放物線が放物線に見えず、形の判断ができません。
  等縮尺のときは右上に「等縮尺」と出ます。
- **見失ったフレームでは線が切れます**。つないで描くと、追跡が飛んだ区間まで滑らかな曲線に見えて
  データが正しいと誤解するためです。
- 物体が複数あるときは色分けして重ね描きし、下の凡例をタップすると個別に表示を切り替えられます。

グラフは平滑化フィルタ適用後の値を描くので、フィルタの効き具合をその場で確認する用途にも使えます。
なお **a-t（加速度）は用意していません**。2 回微分はスマホ解像度のデータではノイズが支配的になり、
かえって誤った印象を与えるためです。

## データの取り出し

「データ」タブの **CSV 保存**、または **共有**（Web Share API 対応端末）から書き出せます。
iOS は共有シート経由の方がファイルアプリに確実に入ります。
出力形式・列構成は Ver.2 と同じ（BOM 付き UTF-8）。

## 精度を出すコツ

- 枠は **20px 以上**。小さい枠は画面のどこにでも一致してしまい、軌跡が暴走します。
- 枠を置く前に **ピンチで拡大**してからタップすると、狙った位置に正確に置けます。
- 端末が重そうなら、設定タブの **探索範囲を 1.8 前後**に抑え、再生速度を 0.5× にすると取りこぼしが減ります。
- 斜めから撮った映像は必ず **平面（四隅）校正**を使ってください。2点間校正では遠近の分がそのまま誤差になります。

## PC 版との差分

| | Ver.2（PC） | Mobile |
| --- | --- | --- |
| レイアウト | 2カラム | 1カラム＋ボトムシート |
| 入力 | マウス | Pointer Events（1本指＝ツール／2本指＝ズーム） |
| 枠の指定 | ドラッグのみ | タップ配置＋ドラッグ |
| 校正点の微調整 | 矢印キー | 十字キー（画面上） |
| 拡大 | 25%刻みボタン | ピンチ（等倍〜12倍）＋ボタン |
| 位置合わせ補助 | なし | 虫めがね |
| CSV | ダウンロード | ダウンロード＋共有シート |
| グラフ | なし | 概形確認モード（軸選択・等縮尺・タップでシーク） |
| 追跡アルゴリズム | — | **同一** |

`src/components/{Header,VideoCanvas,ControlPanel,DataPanel}.tsx` は Ver.2 の名残で、
現在は使われていません（中身は空のスタブ）。
